# Hi, I’m Alborz

I’m an ML platform engineer based in Copenhagen. I build AI tools, self-hosted infrastructure, and small applications that I keep improving over time.

My work spans production MLOps, private AI systems, and developer tooling. Outside work, I maintain a homelab, co-founded [CrossCourt](https://crosscourt.dev), and develop [freest.io](https://freest.io), a rap-battle party game for the browser.

A few things I’ve built:

- [Teleagent](https://github.com/javAlborz/teleagent) — a SIP phone interface for Claude Code and OpenAI Codex.
- [tmux-ai-session-name](https://github.com/javAlborz/tmux-ai-session-name) — follows coding session titles in tmux while preserving window names you set yourself.
- [BoxingVidProd](https://github.com/javAlborz/BoxingVidProd) — multi-camera boxing video production, alongside [video synchronization](https://github.com/javAlborz/MultiVidSynch) and [round detection](https://github.com/javAlborz/RoundBreakDetector).
- [Steam sentiment analysis](https://github.com/javAlborz/steam-sentiment-mlops) — a transformer-based sentiment classifier and MLOps coursework project.

I also write about [building an app platform](https://alborz.hajavi.com/writing/building-a-small-app-platform-on-a-homelab/) and [running a homelab](https://alborz.hajavi.com/writing/homelab-as-a-personal-operating-system/).
